## 完整产品描述

### 🎛️ What is Spectral Delay?

**CopyCat Spectral Delay** is a unique audio effect plugin that breaks your sound into individual frequency bands and lets you control each one independently. Built on STFT (Short-Time Fourier Transform) technology, it opens up a world of creative possibilities that traditional delay plugins simply cannot achieve.

Imagine applying a long delay to only the high frequencies while keeping the bass tight and punchy. Or creating evolving feedback textures that shift across the frequency spectrum. Spectral Delay makes it all possible with an intuitive visual interface.

---

### ✨ Key Features

**🎚️ Per-Frequency Control**
- Apply different delay times to each frequency band
- Set independent gain values across the spectrum
- Control feedback amount for every frequency range

**📊 Real-Time Spectrum Display**
- See your audio's frequency content in real-time
- Switch between input and output visualization
- Choose between line graph or bar chart display

**✏️ Intuitive Curve Editor**
- Click to add control points
- Drag to shape your frequency curve
- Double-click to remove points
- Create smooth or dramatic frequency-dependent effects

**⚡ Flexible Processing**
- FFT Size: 256 to 8192 (trade-off between time and frequency resolution)
- Phase rotation or true delay mode
- Feedback phase invert option
- Dry/Wet mix control

**🔧 Production Ready**
- Full DAW session save/recall support
- Lightweight and CPU-efficient
- Clean, modern interface

### ❓ FAQ

**Q: Is this plugin CPU-intensive?**
A: The plugin is optimized for efficiency. However, larger FFT sizes (4096+) will use more CPU. Start with smaller values and increase as needed.

**Q: What's the difference between Phase and Delay mode?**
A: Phase mode rotates the phase of each frequency bin (instant, no latency). Delay mode applies actual time-based delay to each frequency (adds latency but sounds more like traditional delay).

**Q: Can I automate parameters?**
A: Yes! All main parameters (Multiply sliders, Mix, etc.) can be automated in your DAW.

**Q: Will there be future updates?**
A: Yes, all purchases include free lifetime updates. Planned features include preset browser, additional curve interpolation modes, and more.
