# Overview
我打算做一个音频效果器实现类似Spectral Delay的功能，全名可以叫CopyCat Spectral Delay。在插件的最上方可以显示Spectral Delay字样。我（作者）的昵称叫CopyCat。支持VST，AU格式，使用C++和JUCE框架；

# 音频处理逻辑
输入音频-前期处理- STFT-对于每个频段施加指定的延迟量（可以使用 Per-Bin FFT Buffer）-ISTFT-后处理-输出音频

# UI和操作逻辑
插件为长方形布局，分左右两部分；

左半部分显示STFT后的结果（频谱图）和其他信息（曲线图），两部分为叠加显示，图横坐标为频率（）对数刻度显示），纵坐标在右侧，显示条件的参数的范围；频谱图的纵坐标为db刻度，可以不显示。

右边半部分为操作界面。
右边的最上面一栏可供用户选择控制的参数，目前先做delay time（单位毫秒，范围暂定1-2000），后期可能加上feedback，panning等。
第二栏为操作方式，包含几个选项，在这栏的下面放可以调整的参数，具体如下（后期可能增加）：
1.常数，在左半部分显示一条横线，代表对所有频率施加同一个值，调整的参数为这个参数的值。
2.曲线编辑器，在左半部分显示曲线形状，调整的参数为和构建曲线相关的参数。目前先做参数控制，后期再做断点拖拽或者自由绘制。曲线编辑器我想用斜率和offset，斜率默认值为0，offset根据调整的参数不同而不同，对于delay设置为250ms
右边的最下面一栏为选择FFT窗口大小（256-8192），重叠倍数（2x，4x，8x），切换频谱图显示输入/输出频谱，和mix旋钮。
